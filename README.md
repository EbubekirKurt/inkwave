# InkWave 📖🔊

**An advanced eBook reader with built-in TTS, real-time dictionary, smart note-taking, and reading statistics!**

## 🚀 Features

- 🔊 **Text-to-Speech (TTS)** – Listen to your books while multitasking.
- 📖 **Instant Dictionary & Translation** – Get word definitions and translations on the go.
- ✍️ **Smart Note-Taking & Highlighting** – Organize your notes and highlight key passages effortlessly.
- 📊 **Reading Statistics & Leaderboard** – Track your reading progress, count words, and compete with friends.

## 📂 Project Structure

InkWave is built with **Flutter** and follows a clean, modular architecture:

```
/lib
 ├── models/         # Data models
 ├── services/       # API & backend services
 ├── screens/        # UI screens
 ├── widgets/        # Reusable UI components
 ├── utils/          # Utility functions
 ├── main.dart       # Entry point of the app
```

## 🛠️ Tech Stack

- **Flutter & Dart** – Cross-platform mobile development
- **Provider / Riverpod** – State management
- **Firebase** – Backend & authentication (if applicable)
- **Google TTS API / Flutter TTS** – Text-to-speech integration

## 🏗️ Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/InkWave.git
   ```
2. Navigate to the project directory:
   ```sh
   cd InkWave
   ```
3. Install dependencies:
   ```sh
   flutter pub get
   ```
4. Run the app:
   ```sh
   flutter run
   ```
